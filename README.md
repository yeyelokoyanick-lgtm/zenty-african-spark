# Zenty: Your African E-commerce Hub

Create a modern SaaS web application called "ZENTY", an e-commerce platform designed for African users.

The design must strictly follow a clean, modern dashboard UI inspired by Shopify, using a blue, purple, and white color scheme.

-----------------------------------

GLOBAL STYLE

-----------------------------------

- Primary colors: deep blue (#0A1AFF), purple (#6C2BFF), white

- Soft gradients (blue to purple)

- Rounded cards (border-radius: 12px+)

- Clean spacing and modern typography (Poppins / Inter style)

- Light shadows for cards

- Fully responsive (desktop + mobile)

-----------------------------------

TOP NAVBAR

-----------------------------------

- Left: ZENTY logo (Z icon + ZENTY text)

- Center menu:

  - Tableau de Bord (active)

  - Produits

  - Commandes

  - Paiements

  - Aide

- Right:

  - User avatar

  - Text: "Salut, Karim"

  - Dropdown menu

-----------------------------------

HERO SECTION (WELCOME)

-----------------------------------

Large banner with gradient background (blue → purple)

Text:

- Title: "Bienvenue sur ZENTY, Karim !"

- Subtitle: "Crée ta boutique en ligne et commence à vendre en quelques minutes."

-----------------------------------

ACTION CARDS (3 BLOCKS)

-----------------------------------

Create 3 horizontal cards:

1. Card 1 (Blue):

- Title: "Créer ta Boutique en 5 Minutes"

- Text: "Lance ta boutique en ligne maintenant."

- Button: "Lance ta boutique"

2. Card 2 (Orange):

- Title: "Importer depuis Alibaba"

- Text: "Trouve des produits à succès"

- Button: "Trouve des produits à succès"

3. Card 3 (Purple):

- Title: "Activer Mobile Money"

- Text: "Accepte les paiements MTN & Moov"

- Button: "Accepte les paiements"

Each card should have an illustration (laptop, boxes, smartphone)

-----------------------------------

STATS SECTION

-----------------------------------

4 small cards:

- Ventes du jour: "25 300 FCFA"

- Commandes: "12 nouvelles"

- Visiteurs: "450 aujourd’hui"

- Produits en ligne: "120 actifs"

-----------------------------------

MAIN DASHBOARD CONTENT

-----------------------------------

Split into 2 columns:

LEFT:

- Card: "Ventes & Revenus"

- Tabs: "Cette semaine" / "Ce mois"

- Line chart showing sales growth

RIGHT:

- Card: "Commandes Récentes"

- List of orders:

  - Name (ex: Jacques M.)

  - Status badge (Attente / Expédiée / Nouvelle)

  - Price (FCFA)

- Button: "Voir"

-----------------------------------

BOTTOM SECTION

-----------------------------------

LEFT:

- Help card:

  - Title: "Centre d’Aide"

  - Text: "Besoin d’aide ? Consulte nos guides"

  - Button: "Accéder"

RIGHT:

- Marketing card:

  - Title: "Boostez Vos Ventes !"

  - Text: "Lancez vos pubs facilement sur Facebook"

  - Button: "Créer une Campagne"

-----------------------------------

FUNCTIONAL REQUIREMENTS

-----------------------------------

- Static dashboard UI for now (no backend required yet)

- Components should be modular

- Prepare structure for future dynamic data

- Clean code structure

-----------------------------------

GOAL

-----------------------------------

Recreate a professional SaaS dashboard UI that looks like a real product ready for launch in Africa.
